# Play the prototypes

Live arcade: https://haki-s-playtest-arcade-58ip5f.v2.appdeploy.ai/

Use Play solo + AI, or Create friend room and Copy invite. The three solo games have optional AI autopilot. All ten have touch and keyboard controls.

The hosted fallback runs simulation in the host browser. Keep the host tab open and active. Closing the host closes that room. The included native Node server instead runs an authoritative simulation and supports host-control transfer. These are simplified Canvas prototypes, not Unity projects or complete games.

Railway authentication is connected, but project creation was blocked by the expired account trial. No plan was purchased. Ten new remote GitHub repositories were not created: source remains on this isolated branch, and the delivery workflow exports ten independent local Git repositories for download.

The live fallback adapter and the native server are separate implementations. Local native-server tests do not prove live AppDeploy multiplayer behavior. The deployment reported no frontend or backend errors, but a two-device hosted playtest remains necessary.
